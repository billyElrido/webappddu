DDU APP - PETUNJUK DEPLOY HOSTINGER

PAKET APLIKASI: dduapp-hostinger-ready-v11.zip
Upload melalui Deploy Aplikasi Web Node.js > Upload file.

Konfigurasi:
- Node.js: 22.x
- Build command: npm ci
- Start command: npm start
- Entry file: server.js

Environment variables:
NODE_ENV=production
DDU_HTTPS=1
DDU_SESSION_IDLE_MINUTES=30
DDU_SESSION_ABSOLUTE_HOURS=8
DDU_TRUST_PROXY=1
DDU_INITIAL_PASSWORD=<buat password kuat>
DDU_LARGE_DISBURSEMENT_LIMIT=5000000
DB_HOST=localhost
DB_PORT=3306
DB_NAME=<nama lengkap database dari hPanel>
DB_USER=<nama lengkap pengguna database dari hPanel>
DB_PASSWORD=<password database>
DB_SSL=0

Urutan aman:
1. Buat database dan pengguna MySQL di hPanel.
2. Untuk instalasi baru saja, impor database/mysql-schema.sql melalui phpMyAdmin.
3. Untuk pembaruan aplikasi dengan database yang sudah berisi data, jangan impor ulang database.
4. Upload dan deploy dduapp-hostinger-ready-v11.zip.
5. Isi atau pertahankan environment variables di hPanel.
6. Buka /api/health; hasil yang benar memuat database=mysql dan ok=true.
7. Login dan uji dashboard, Input Realisasi, serta unduhan template Excel.

Pembaruan tahun buku:
- Kolom target_year dan tabel fiscal_years dibuat otomatis saat aplikasi pertama kali dijalankan.
- Tabel pengaturan dan kolom batas persetujuan anggaran dibuat otomatis saat aplikasi terbaru dijalankan.
- Tabel academic_years, donor_class_assignments, serta kolom jenjang/kelas/tahun ajaran dibuat otomatis saat aplikasi terbaru dijalankan.
- Relasi transaksi ke profil donatur dan pembukuan penggunaan anggaran dimigrasikan otomatis saat aplikasi terbaru dijalankan.
- Jangan mengimpor ulang database lama ke database produksi yang sudah berisi data.
- Setelah deploy, buka Program & Target dan pastikan tahun berjalan berstatus Berjalan.

Jangan mengunggah .env, ddu_control.db, migration-data.json, atau node_modules.
